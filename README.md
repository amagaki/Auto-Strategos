# Auto-Strategos

**進軍型オートストラテジー** — チェス風 8×8 盤面で駒を購入・配置し、自動進行で敵陣最奥到達を競うブラウザゲーム。

> 2026 GW 5/2 完成、kawashima × Claude Code(Anthropic Opus 4.7)の共同制作。

---

## 🎯 目的

自分の駒を **敵陣最奥(画面上端)** に **3 体到達** させて勝利。
逆に敵駒を **自陣最奥(画面下端)** に **3 体到達** されると敗北。

両者同時に 3 体到達した場合は **引き分け**。

---

## 🎮 1 サイクルの流れ

1. 画面下の **shop** で駒のカードをクリックして選択
2. 盤面の **自陣青背景マス**(下 2 行)をクリックして配置(所持金を消費)
3. 必要なら他の駒も購入・配置(リロール 1g で shop 入替)
4. **[Go &gt;]** ボタンで **3 ターン分** が自動進行
5. 全駒が動き、衝突したら自動戦闘
6. 次サイクルへ(基本収入 +3g + 利息)

サイクルを繰り返し、いずれかが 3 体到達した時点でリザルト画面へ。

## ⚔️ 駒の種類(7 種 + 障害物)

| 駒 | 動き | 攻撃範囲 | HP | ATK | コスト |
|---|---|---|---|---|---|
| **兵士 (歩)** | 前 1 / 斜め前 1 | 隣接 3 マス | 2 | 1 | 1g |
| **斥候 (斥)** | 斜め前 1 のみ | 隣接 3 マス | 1 | 1 | 2g |
| **騎兵 (騎)** | 前 2 / 前 1 / 斜め前 1 | 隣接 3 マス | 2 | 2 | 4g |
| **弓兵 (弓)** | 前 1 / 斜め前 1 | **遠距離 2 マス**(味方で遮られる) | 1 | 2 | 5g |
| **重装兵 (重)** | 前 1 のみ | 前 1 | 5 | 1 | 6g |
| **槍兵 (槍)** | 前 1 のみ | 前 1 / 斜め前 1 / **横 1**(動かず横払い) | 3 | 1 | 3g |
| **暗殺者 (暗)** | 斜め前 1 / 斜め前 2 | 隣接 | 1 | 3 | 6g |
| **障害物 (■)** | 動かない | — | 3 | 0 | 初期配置のみ |

**障害物**は両陣営に味方・敵側に分かれて初期配置されます:
- **自陣の壁** = 同盟扱い、自分の駒は攻撃しない
- **敵陣の壁** = 破壊して進む必要あり

## ⚙️ 設定項目

タイトル画面 → 「ゲーム設定」 から:

| 項目 | 選択肢 |
|---|---|
| **AI 戦略** | バランス / 攻め寄り / 守り寄り |
| **AI 難易度** | やさしい(初期金 3, 1 駒/ターン) / ふつう(5, 2) / むずかしい(7, 3) |
| **障害物パターン** | 標準(8 マス) / なし / 多め(12 マス分散配置) |
| **出撃編成** | shop に並ぶ駒種を 5+ 種から自由選択(全選択がデフォルト) |

設定は **localStorage** に保存され、リロード後も保持。

## 💡 UX 機能

- **ホバー予測**: 駒にマウスを合わせると **3 ターン先までの予測経路** を矢印で表示
- **動ける範囲ハイライト**: ホバーした駒が動ける先のセルを盤面に直接表示
  - 移動可能セル: 陣営色の塗り
  - 攻撃可能(敵駒/敵壁): 赤透明
  - 弓兵射程: 紫塗り(空マスも可視化)
  - 槍兵横払い: 緑塗り(空マスも可視化)
- **凡例パネル**: 画面右に各駒の能力一覧を常時表示(トグル可)
- **チュートリアルモーダル**: 初回起動時に自動表示、画面右上「?」ボタンで再表示

## 🛠️ 開発・実行

### 必要環境
- Node.js 18 以上
- モダンブラウザ(Chrome / Firefox / Edge)
- 推奨ディスプレイ解像度: **1080p 以上**(900p でぎりぎり収まる)

### 起動方法

```bash
npm install
npm run dev
# ブラウザで http://localhost:5181/ を開く
```

### ビルド(配信用)

```bash
npm run build
npm run preview  # 配信前確認
```

ビルド出力は `dist/` に生成され、`base: './'` 設定により**ローカル直接開き / GitHub Pages / 任意のサーバー** で配信可能。

## 🧠 設計の特徴

### Onitama 流の動きグリッド表記
駒アイコンと shop card に **3×N の点群グリッド**(● = 動ける先、○ = 動けない)で動きパターンを表現。Onitama というボードゲームから着想。チェスのような暗記型ではなく、**初見プレイヤーが視覚で動きを理解**できる。

### 同時解決される遠距離攻撃
弓兵 vs 弓兵が互いに射程内の場合、順次処理だと「先に処理された方が一方的に勝つ」バグが発生。これを **遠距離 + 槍兵横払いを同時解決** することで相打ちが成立する設計に。

### 決定論的な駒の AI
ホバー予測の結果と実際の進行が一致するように、駒の動きの選定にランダム要素を排除(同点候補は配列の先頭固定)。

### アフォーダンス重視の UX
- ホバー時に動ける範囲を盤面に直接表示(chess.com 流)
- 射程を「⤴ 射程2」「↔ 横払い」と明文化
- HP の色変化(緑/橙/赤)で残量を視覚化
